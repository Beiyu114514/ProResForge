# PCM→MP4 音频兼容性修复

**修复日期**：2026-10-09  
**问题编号**：M-新01

---

## 问题描述

### 症状
ProRes MOV 转码到 MP4（H.264/H.265）时失败，错误信息：
```
E/FFmpeg: [mp4 @ ...] Tag sowt incompatible with output codec id '65536' (ipcm)
nativeRun rc=-1094995529
```

### 根因
1. DNG zip → ProRes 转码生成的 MOV 包含未压缩 PCM 音频（codec_id 65536）
2. 再次转码到 MP4 时，音频默认走 `copy` 模式（直通）
3. 代码清空 `codec_tag` 让 muxer 自动选择，MP4 muxer 选择了 MOV 专用的 `sowt` tag
4. MP4 容器不接受 `sowt` 等 MOV 音频 tag，导致写入失败

### 触发条件
- 输入：自己生成的 ProRes MOV（包含 PCM 音频）
- 输出：MP4 容器
- 音频模式：`copy`（��认）

---

## 修复方案

### 实施的修复（方案 A）

**位置**：`app/src/main/cpp/transcode.cpp:2218-2233`

**修改内容**：在音频模式判断逻辑中，新增 PCM→MP4 兼容性检查：

```cpp
// 新增：PCM 族不能 copy 进 MP4
if (audio_mode == "copy") {
    bool is_pcm = (aid >= AV_CODEC_ID_FIRST_AUDIO && aid <= AV_CODEC_ID_PCM_F16LE);
    bool is_mp4 = (std::strcmp(oc->oformat->name, "mp4") == 0 || 
                  std::strcmp(oc->oformat->name, "ipod") == 0 ||
                  std::strcmp(oc->oformat->name, "m4v") == 0);
    if (is_pcm && is_mp4) {
        av_log(nullptr, AV_LOG_INFO, 
               "transcode: PCM audio cannot copy to MP4, auto fallback to AAC\n");
        audio_mode = "aac";
    }
}
```

**行为变化**：
- **修复前**：ProRes(PCM) → MP4 失败，错误码 1094995529
- **修复后**：自动降级到 AAC 重编码（48kHz, 160kbps, stereo），转码成功
