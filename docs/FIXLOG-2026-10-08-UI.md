## 工具经验(本轮踩坑)

- 本机 `screen_capture` 工具不可用(报 `value.embeddedRef must be an object`)→ 改用 `uiautomator dump` + `adb pull` + 主机侧 pwsh 正则解析。
- 设备侧长管道(`cat | tr | grep | sort`)偶发 `Segmentation fault`;解析一律放主机侧,单条 `grep` 也别嵌套太长。
- `pm revoke POST_NOTIFICATIONS` 会**杀掉应用进程**(logcat 可见 `RuntimeException: Bad file descriptor` @ `ActivityManager.getService`);本应用理由框的触发条件是「已撤销 && 未问过」(`HomeScreen.kt:128-133`),所以可直接复现,无需先走系统弹窗拒绝。
- Kotlin 块注释**可嵌套**:注释文本里出现 `/*` 会导致 `Syntax error: Unclosed comment`(本次真实踩坑,已修)。
- pwsh 写文件:读/写都用 `[System.IO.File]` + `UTF8Encoding($false)`;`Get-Content -Raw` 会按 ANSI 读 UTF-8 造成假失败。
